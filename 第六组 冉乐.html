// about this ui

界面介绍

本站以「终端诗学」为设计语言——把深夜写代码时那种专注、安静而温柔的氛围，做成一套完整的视觉系统。

设计哲学

终端诗学：等宽字体、琥珀色提示符、深靛蓝夜幕——所有视觉元素都取自开发者最熟悉的终端窗口，唤起「回到主场」的安全感。
克制的层次：玻璃拟态面板只用于承载内容容器；强调色仅琥珀一种主导，薄荷/紫罗兰/玫瑰按语义使用，杜绝彩色噪音。
可感知的反馈：卡片悬停浮起、音乐律动驱动粒子加速、每个操作都有 Toast 回声——界面的每一次呼吸都应被用户看见。

六大特性

📱

响应式适配

桌面侧边栏 / 平板折叠 / 手机底部 Tab + 抽屉式布局，375px 起全部可用。

♪

本地合成音乐

背景音乐由 Web Audio API 实时合成（Lo-Fi 和弦 + 鼓组 + 旋律），无需任何音频文件，断网可听。

✎

打字机叙事

首页标题逐字浮现并轮换文案，光标呼吸闪烁，营造「正在运行」的活感。

⌕

本地搜索记录

搜索历史存储于浏览器 localStorage，支持逐条删除、一键清空，数据不出本机。

◐

无障碍基线

正文对比度 ≥ 4.5:1，焦点可见，语义化标签 + aria 属性，尊重系统减弱动效偏好。

⚡

零依赖单文件

不加载任何外部字体/脚本/图片，一个 HTML 文件即整站，可离线打开、任意静态托管。

技术栈与规格

  • HTML / CSS语义化结构；CSS 自定义属性承载全部设计令牌；Grid + Flex 布局。
  • JavaScript原生 ES2018+，无框架、无构建。路由为 hash 内存切换，状态即数据渲染。
  • Web Audio APIAudioContext · GainNode · BiquadFilter · AnalyserNode
  • Canvas粒子背景 requestAnimationFrame · 音乐可视化频谱
  • 本地存储localStorage['cv_search_history']
  • 断点1024px（栅格折叠）· 768px（侧栏→Tabbar）· 480px（紧凑模式）
  • 动效prefers-reduced-motion 全局降级

交互清单
